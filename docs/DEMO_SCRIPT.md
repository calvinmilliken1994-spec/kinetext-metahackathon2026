# Three-minute demo script (user-requested format)

| Time | Show | Required real evidence |
|---|---|---|
| 0:00–0:25 | Educator needs an interactive lesson from a static forces page | Licensed real source; explain teacher task |
| 0:25–0:55 | Upload and Meta multimodal understanding | Real source/diagram analysis, objectives and page anchors |
| 0:55–1:40 | Generate and interact with working simulation | Actual Meta run IDs, spec, functioning mass/net-force controls |
| 1:40–2:20 | Verify, detect an intentionally seeded defect, repair | Clearly label seeded fault; actual failing test, Meta plan, actual rerun |
| 2:20–2:45 | Edit/reuse and student experience | Teacher edit invalidates old verification; usable new artifact |
| 2:45–3:00 | Impact and measured contribution | Actual latency/token/cost/pass measurements and Meta roles |

No fabricated progress/tool calls. Technical inspection panel reads genuine event receipts. Precomputed safe examples are permitted only with visible recorded/precomputed labels, date, model and matching test artifacts; never portray recordings as live execution. If repair fails, show the blocked state rather than a staged success. This is a planned script: no live product demo exists yet.

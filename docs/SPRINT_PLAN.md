Relative days only: confirm official eligible dates/deadline from participant FAQ before assigning calendar dates. Gates can delay the sequence; do not compress safety checks to fit an invented deadline.

| Day | Milestone / owner | Depends on | Exit evidence |
|---|---|---|---|
| 1 | Rules, master mission, credits/auth, exact model discovery, budget; Calvin + Anthropic Opus 5.5 lead | FAQ/master instructions/account access | Verified requirements matrix; real direct Meta smoke receipt; approved scope |

| 7 | Teacher edit/reuse, student artifact and publish gate; Qwen + Anthropic | Days 5–6 | Revision invalidates prior validation; only verified revision publishes; student interaction works |
| 8 | SAM diagram regions + concept mapping; Muse integration | Day 7 stable core + sam-3.1 account availability | Real mask/box outputs or labeled manual annotation; core remains usable without SAM |
| 9 | Budget, security/accessibility review; controlled benchmarks | Days 7–8 + separate benchmark approval | No-network sandbox if advanced path used; spend/timeout/termination tests; measured provider comparison |
| 10 | Independent final review, 3-minute demo and submission | Day 9 + official rules/deadline | Full real journey regression, provenance/licenses, scrubbed public repo candidate, truthful demo |

Parallelism starts only after Day 2 boundaries are frozen. Day 4 deterministic engine can proceed alongside Day 3 integration with the frozen contract, not competing schema edits. Voice, generated illustrations, Glimmer and self-hosting are stretch investigations after the core is stable. Baseten benchmark is optional and never a prerequisite for core direct Meta functionality.

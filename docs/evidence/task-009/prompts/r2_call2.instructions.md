### Interface decisions from the lead (follow exactly)
- `MetaErrorCode` gains `'LEDGER_ERROR'`; `META_ERROR_MESSAGES.LEDGER_ERROR = 'spend ledger unavailable; operator recovery required'`. All other codes and messages stay exactly as they are.
- `MetaError` gains the public optional field `reservedUnknownUSD?: number` and the matching constructor option (set when given, like `chargedUSD`). Constructor shape and message rule unchanged (second argument ignored).
- Accounting per `complete()` call: keep two running sums, `knownUSD` (attempts settled at a known amount: usage cost for a 2xx with valid usage, 0 for a 4xx rejection) and `reservedUnknownUSD` (attempts charged at their full reservation because the outcome was uncertain). `chargedUSD = knownUSD + reservedUnknownUSD`; `costBasis = reservedUnknownUSD > 0 ? 'reservation' : 'usage'`. EVERY `MetaError` thrown by `complete()` carries `chargedUSD`, `reservedUnknownUSD` and `costBasis` (errors before any reservation — INPUT_TOO_LARGE, DEADLINE_EXCEEDED before the first attempt, a refused first reservation — carry 0, 0, 'usage'). Every receipt (success and error receipts) carries `estCostUSD = chargedUSD`, `reservedUnknownUSD` and `costBasis` computed the same way. Do not round these amounts.
- N-02, reserve: if `ledger.reserve` throws an `Error` whose message is exactly `'BUDGET_EXCEEDED'` → `MetaError('BUDGET_EXCEEDED')`; ANY other exception (LEDGER_CORRUPT, LEDGER_CLOSED, INVALID_AMOUNT, I/O errors, non-Error throws) → `MetaError('LEDGER_ERROR')`. In both cases nothing is sent for that attempt and earlier attempts' liabilities stay in chargedUSD.
- N-03, reconcile: if `ledger.reconcile` throws, stop immediately (no retry, no further ledger writes) and throw `MetaError('LEDGER_ERROR')` with that attempt counted at its FULL reservation in `reservedUnknownUSD` (conservative, regardless of what the response said). No receipt is required on this error.
- N-03, envelope: after a 2xx body parses as JSON, if the value is not a plain object (null, array, string, number, boolean), or `choices` is not an array, or `choices[0]` is not a plain non-null non-array object, the outcome is uncertain: reconcile the attempt at its full reservation and throw `SERVER_ERROR` (no retry, same as today's unparseable 2xx body). Only after this validation may fields be dereferenced. A valid envelope whose `message`/`content` is missing still gives `EMPTY_OUTPUT` as today.
- N-03, no unaccounted exit: from the moment a reservation succeeds until that attempt is reconciled, any unexpected exception that is not already a `MetaError` from this function must not escape raw: if the attempt is not yet reconciled, try to reconcile it at its full reservation (if that reconcile throws → `LEDGER_ERROR` as above), then throw `MetaError('SERVER_ERROR')` with the cost metadata. Track per attempt whether it was reconciled so no attempt is reconciled twice.
- R-11, retry sleep: `MetaClientOptions.sleep` becomes `(ms: number, signal?: AbortSignal) => Promise<void>` (existing injected sleeps that take only `ms` remain assignable). The client passes the job signal to it. The default sleep is abortable: it resolves (or rejects) as soon as the signal aborts and clears its timer. The client must not rely on an injected sleep honouring the signal: it races the sleep against the job signal's `abort` event (remove the listener afterwards, leave no timers or listeners behind). After the sleep, if the job signal is aborted → `DEADLINE_EXCEEDED` with the first attempt's liability; no second reservation and no second fetch.

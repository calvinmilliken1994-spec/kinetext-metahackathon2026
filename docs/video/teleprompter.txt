Hi, I'm Calvin. I built this on my own during the hackathon. Before October 27th, this repo held a setup scaffold and no product. Everything you're about to see was built between October 27th and November 4th.

[2]
It's for teachers. Pick a licensed page, or paste your own, and Meta's models turn it into a short lesson with interactive parts. Each part is tied to the sentence it came from and checked against the page. These are lessons it built earlier.

[3]  RECORDING: press F8 and stay quiet until "Lesson ready".
VOICED LATER over the sped-up build:
This is a live build on Muse Spark 1.3, through Meta's Model API. The strip shows each call as it happens.

Muse reads the page and writes the summary first. Each key point lights up the sentence it came from.

Then it writes the parts. Before a part appears, code checks its quotes, numbers and structure against the page. If a check fails, the part goes back to Muse with that check, and Muse revises it.

For the diagram, Muse Spark finds each labelled part on the USGS figure, and SAM 3.1, Meta's segmentation model, outlines it to confirm. If they disagree, the check fails and the part is reworked.

I've sped up the middle. The whole build took ⟨about two minutes⟩ and cost ⟨about twenty cents⟩.

[4]
Students drag each name onto its number, and nothing is marked until they check. Checks and run details shows every check behind the lesson, and when Muse revised a part, which check failed, what it changed, and the figure before and after.

[5]
Every lesson says "Needs review" until a teacher reads each part and publishes it. Published lessons go on the shelf: ten so far, across eight subjects.

[6]
It runs on three Meta models: Muse Spark 1.3 on Meta's API, Muse Spark Open, the open-weight model, served on Modal, and SAM 3.1 for the diagrams. I built 194 lessons with each Muse model. Spark 1.3 made a working lesson 189 times, Spark Open 178. Muse's own repairs rescued 45 parts on Spark 1.3 and 70 on Spark Open.
